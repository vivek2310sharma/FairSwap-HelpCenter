# FairSwap Help Centre

India-first, mobile-first Help & Safety knowledge centre for [FairSwap](https://fairswap.in).

- **Planned production URL:** https://help.fairswap.in
- **Technology:** Next.js App Router, TypeScript, Tailwind CSS, Git-backed content
- **Launch languages:** English and Hindi
- **Hosting:** Vercel (commercially licensed plan)
- **Backend:** None required for public Help Centre V1
- **Existing support:** Link to the established FairSwap ticket, reporting, and grievance workflows. Do not duplicate the backend.
- **Business and Careers:** Clearly labeled Coming soon pages; no applications, bookings, payments, or lead-collection forms in V1.

The repository's implementation blueprint, architecture, content catalogue, UX specification, Vercel checklist, security requirements, and Codex kickoff instructions will be tracked in `docs/` and `AGENTS.md`.

No production environment is configured by this README.
